# مختبر القياسات الكهربائية — Electrical Measurements Virtual Lab

مختبر عربي ثلاثي الأبعاد لسبع تجارب من مختبر القياسات الكهربائية. الطالب يوصّل الأسلاك بنفسه بين أطراف الأجهزة على طاولة المختبر، ومحلّل دوائر داخلي يحسب قراءات الأجهزة من التوصيل الفعلي (التوصيل الخاطئ يعطي قراءات خاطئة كما في الواقع). لكل تجربة: المختبر، الشرح، الحسابات، والمناقشة.

## التجارب

| # | التجربة | ما تحاكيه |
|---|---------|-----------|
| 1 | تصميم فولتميتر تيار مستمر متعدد المديات | جلفانوميتر 0.3 V / 6000 Ω مع مقاومات التوالي Rs1–Rs4 لمديات 3، 6، 9، 12 V، مفتاح المديات، مجهز قدرة، فولتميتر مرجعي، ورقة تصميم تتحقق من حساباتك |
| 2 | تصميم أميتر تيار مستمر متعدد المديات | الشنت لمديات 3، 6، 9، 12 mA، توزّع التيار بين الملف والشنت، خطأ الإدخال، الوضع OFF الخطِر |
| 3 | طرق قياس المقاومة وقنطرة ويتستون | القنطرة المتزنة (صندوق مقاومات عشري + كاشف صفر) وغير المتزنة، شفرة الألوان مع اختبار، طريقة الأميتر والفولتميتر بالتوصيلين، الأوميتر التناظري والرقمي |
| 4 | مجزئ الجهد الدوّار بالفولتميتر التناظري والرقمي | مقبض دوّار 270°، أوميتر، تأثير التحميل وحساسية الفولتميتر (Ω/V)، رسم Vout مقابل الموضع |
| 5 | قياس المحاثة | مولّد دوال، ملفات مجهولة بمقاومة سلك r، تساوي VR و VL، مخطط الطور وراسم الإشارة |
| 6 | قياس السعة | متسعات مجهولة، تساوي VR و VC، C = VR / (2πfRVC) |
| 7 | المحوّل التفاضلي الخطي المتغير LVDT | وحدة KL-620، ضبط VR5 إلى Vp = 10 V، إيجاد موضع الصفر، الإزاحات ±1، ±2، ±3 mm، منحنى الخطية |

## التشغيل

الموقع ملفات ثابتة (HTML و CSS و JavaScript) بلا خطوة بناء. يحمّل مكتبة three.js 0.128 من cdn.jsdelivr.net، لذلك يحتاج اتصالاً بالإنترنت ومتصفحاً يدعم WebGL:

- افتح `index.html` مباشرة في المتصفح، أو
- فعّل GitHub Pages على الفرع الرئيسي (Settings → Pages → Deploy from a branch) لينشر الموقع على الإنترنت.

تُحفظ القراءات المسجّلة في متصفح الطالب نفسه (localStorage) وتبقى عند إعادة فتح الصفحة.

## هيكل الملفات

```
index.html                 الصفحة الوحيدة (توجيه عبر #اسم-التجربة)
assets/css/style.css       التصميم (الوضع الفاتح والداكن، متجاوب مع الهاتف)
assets/js/core.js          الأدوات المشتركة: التنسيق، أزرار التحكم، رسوم الدوائر، الرسم البياني، قائمة الخطوات
assets/js/lab3d.js         محرك الطاولة ثلاثية الأبعاد: الأجهزة، الأطراف، الأسلاك، ومحلّل الدوائر (DC و AC)
assets/js/app.js           الصفحة الرئيسية، التبويبات، التنقل
assets/js/exp-*.js         تجربة لكل ملف (exp-ac.js يضم تجربتي المحاثة والسعة)
```
